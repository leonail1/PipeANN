\begin{frame}[c]{需求 4：单查询 RSS}
    \centering
    \begin{columns}[c,onlytextwidth]
        \column{0.66\textwidth}
        \centering
        \includegraphics[width=0.98\linewidth,height=0.54\textheight,keepaspectratio]{../../experiments/r116_suite/exp4_delete_reinsert_selectivity/rss_by_selectivity.png}

        \column{0.32\textwidth}
        \centering
        \begin{minipage}{0.96\linewidth}
            \scriptsize
            \raggedright
            \textbf{结论：满足 30MB 限制。}

            \vspace{0.25em}
            口径：干净单查询进程总内存；query vector 和过滤 label 通过命令行传入，不加载 query file、groundtruth 或 query spmat。

            \vspace{0.25em}
            30 个 RSS 点峰值为 \textbf{22.26 MiB}。

            \vspace{0.25em}
            范围：1M initial 为 12.52--17.75 MiB；750k delete 为 15.22--20.60 MiB；1M reinsert 为 16.80--22.26 MiB。

            \vspace{0.25em}
            重插 1M 更高，主要因为非 identity tags 会加载 dense tag table；初始 1M 走 equal mapping。
        \end{minipage}
    \end{columns}
\end{frame}

            \item 1M：raw 488.28 MiB；其他文件合计 1008.41 MiB，其中 disk.index 976.57 MiB，PQ compressed 30.52 MiB，PQ pivots 0.13 MiB，labels.densebit 1.19 MiB。
        \end{itemize}
    \end{minipage}
