\begin{frame}[c]{需求 0：从 0 插入与阈值前搜索}
    \centering
    \begin{minipage}{0.94\textwidth}
        \scriptsize
        从 0 数据量向索引中插入向量时，进入纯内存模式；0--10k 向量直接插入内存数组，并执行精确近邻搜索。该阶段不训练 PQ、不生成磁盘图；索引中向量数超过 10k 后，再一次性落盘为磁盘图索引。

        \vspace{0.2em}
        SIFT1M 前 10k 向量实验中，10k 以内全部保持纯内存模式；单查询峰值 RSS 最高约 \textbf{32.3 MiB}，接近 30MB 要求；平均搜索延迟最高约 \textbf{0.20 ms}，显著低于 10ms 延迟要求，10k 附近 QPS 约 \textbf{5k}。

        \vspace{0.2em}
        \textcolor{red}{结论：已支持从 0 数据量开始插入；落盘前延迟满足要求，内存占用与 30MB 目标基本一致。}
    \end{minipage}
